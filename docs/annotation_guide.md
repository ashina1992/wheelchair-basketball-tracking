# アノテーション指針

自前データセット(P2)でバウンディングボックスを付けるときのルール。
複数回に分けて作業しても基準がぶれないよう、迷ったらここに追記してから作業を続ける。

## 対象フレーム

- 試合の広角ショット(コート全体を俯瞰するメインカメラ)のみ。クローズアップ、サイドラインカメラ、リプレイ、観客席、広告は対象外
- `scripts/prepare_dataset.py extract` が広角ショットらしいフレームを自動で選ぶが、対象外のものが混ざっていたら CVAT 上で削除する

## クラス

| ID | クラス | 付ける対象 | 付けない対象 |
|---|---|---|---|
| 0 | `player` | コート上(ライン際を含む)の選手。**選手と車いすを合わせた全体**を1つの箱で囲む | ベンチの選手・スタッフ、観客 |
| 1 | `ball` | 試合で使っているボール(保持中・空中・床上すべて) | ウォームアップ用のボール、看板や床の絵柄 |
| 2 | `rim` | リング(輪の部分)。ネットは含めない | バックボード |
| 3 | `referee` | 審判 | テーブルオフィシャル、カメラマン |

## 箱の付け方

- **player**: 頭の上端から、車いすの車輪の接地点(一番下)まで。左右は車輪の外側まで。腕を伸ばしている場合も腕を含める。選手の位置はこの箱の下端中央をコート座標に変換して求めるため、**下端を車輪の接地位置に正確に合わせる**ことを最優先にする
- **ball**: ボールの外接矩形。ぶれて楕円に写っている場合は、ぶれた範囲全体を囲む
- **rim**: 正面から見て楕円になっている輪の外接矩形
- **referee**: 頭から足元まで

## 遮蔽(重なり)の扱い

- 他の選手に隠れている部分は、**見えている部分から推定して、全体の範囲**を囲む(隠れている車輪の位置も推定する)
- 全体の半分以上が隠れていて位置を推定できない選手は付けない
- ボールが手で半分以上隠れていても、位置が分かれば付ける。完全に隠れていれば付けない
- 画面の端で切れている選手は、見えている範囲だけを囲む

## 作業手順(CVAT)

1. `python scripts/prepare_dataset.py extract <video> --game <試合名> --out data/dataset/raw` を試合ごとに実行する
2. `python scripts/prepare_dataset.py cvat-export data/dataset/raw --n 300 --zip data/dataset/cvat_batch1.zip`
3. CVAT でタスクを作成し、ラベルを `player`, `ball`, `rim`, `referee` の順で定義して、`data/dataset/cvat_batch1/` の画像をアップロードする
4. 「Upload annotations」で `cvat_batch1.zip` を「YOLO 1.1」として読み込む(既製モデルの下書きが入る)
5. 下書きを修正する。特に: 車いすまで含めて箱を広げる、ボールを追加する、リングを追加する、ベンチ・観客の箱を消す
6. 「Export task dataset」で「YOLO 1.1」を選んで書き出し、`cvat-import` で取り込む

## 試合名の付け方

- 動画のファイル名(拡張子なし)をそのまま試合名にする(例: `Japan_v_Poland_men`)
- 1試合を前半・後半など複数ファイルに分けて録画した場合は、末尾に `_1`, `_2` を付ける(例: `Japan_v_Poland_men_1.mp4`, `Japan_v_Poland_men_2.mp4`)。分割(`split --test Japan_v_Poland_men`)やサンプリングでは1試合としてまとめて扱われる
- 試合名は train/val/test の分割に使うため、同じ試合のフレームが別の試合名にならないようにする
